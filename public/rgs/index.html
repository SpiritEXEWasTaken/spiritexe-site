RGS

A free, open-source game backend you run yourself. Accounts, saves, moderation and an admin panel, on your own machine.

What it does

Accounts

Sign-up and login, optional 2FA for players, and 2FA required for staff. Headsets sign in with a short code, so nobody types a password in VR.

Private by design

Players never see each other's IP addresses. Passwords are hashed, 2FA keys are encrypted, and everything is encrypted in transit.

Moderation

Roles, bans, an audit log, and player reports from inside your game, with an optional Discord channel feed.

Cloud saves

Named save slots per game and per player, so progress follows players between devices.

Updates without surprises

Schedule restarts with in-game countdowns, and turn away old game versions with a clear "please update" message.

Runs anywhere

One program for Linux, Mac (a Mac mini works great) or Windows. Free, MIT licensed, and $0 to host at home.

Get started

  1. Download RGS for your system from the releases page, or build it with cargo build --release.
  2. Follow the install guide to run it as a service.
  3. Make an RGS account here (2FA required) and link your server. Only your account can see the servers you link.
  4. Open its Admin panel from there and create the server's owner account. Your server connects out to this website, so the panel, player sign-in and your games reach it from anywhere, with nothing opened on your network.
